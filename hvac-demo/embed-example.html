Embed example

This plain page shows the only code a client site needs: two script tags pasted before </body>. The widget loads its own CSS. The owner panel, presets and demo page aren't needed.

<script src="https://YOUR-HOST/tecchat/bot-config.js"></script>
<script src="https://YOUR-HOST/tecchat/tec-chat.js" defer></script>

The chat on this page runs a real-client style config generated by tools/new-client.py for a fictional plumber: request-mode booking (the customer picks a day and time window, the office confirms), English/Spanish, no example prices. It has no webhook, so leads stay in this browser.
