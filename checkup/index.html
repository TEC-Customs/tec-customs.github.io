      Questions

      Is it really free?

      Yes. There is no sign-up and nothing to buy. The fix list is yours to use however you like, including fixing things yourself.

      Where do the scores come from?

      From Google Lighthouse, the same open-source test behind Google PageSpeed Insights. The test is run by Google PageSpeed Insights when it is available, or by the Microlink API otherwise. The overall score is the average of the four Lighthouse category scores.

      Why did my score change when I ran it again?

      Speed scores move a bit between runs because network and server conditions change. Look at the fix list more than the exact number.

      Do you store my website or results?

      No. The checkup runs in your browser. The address you enter is sent only to the testing service (Google PageSpeed Insights or Microlink) to run the test. This page has no tracking or analytics.

      Why did it say the daily limit was reached?

      The free testing services allow a limited number of checks per day. If you hit the limit, try again tomorrow, or request help and I will run the checkup for you.
